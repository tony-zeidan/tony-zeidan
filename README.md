# Tony Zeidan
Hi there! :smiley:

My name is Tony and I'm a Software Developer at Canadian Bank Note Company, Limited. I work on large-scale online applications, mostly backend in Java and Spring Boot with Vaadin and Angular on the front end.

I picked most of this up at Carleton University in the Software Engineering program. Outside of work I mess around with new frameworks and grind LeetCode. I also wrote GeoHexViz, a Python package for hexagonally binned geospatial maps, which ended up published in the Journal of Open Source Software.
